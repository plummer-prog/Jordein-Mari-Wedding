# Wedding Seating Chart Instructions
1. Open index.html in a text editor.
2. Replace guest names and tables in the "guests" object.
3. Replace floorplan.png with your actual floor plan image.
4. Adjust table positions (top/left) in the HTML to match your layout.
5. Test by opening index.html in your browser.
